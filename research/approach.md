# Platform Research Approach

## 1. Identifying the Platform

I started by looking at the network traffic generated by the Rouses store (`orderonline.rouses.com`). The API requests were sent to `https://production-us-1.noq-servers.net`. 

Additionally, investigating the Rouses Markets mobile app on the Apple App Store revealed that its publisher is **eGrowcery Pty Ltd**. The network requests combined with this app developer footprint confirm that Rouses Markets is built on the **eGrowcery** white-label e-commerce platform.

## 2. Signals and Patterns to Enumerate Stores

To find other stores using the same platform, I utilized a few approaches:

**A. App Store Publisher Search**
Since eGrowcery builds white-label apps for their clients, searching the iOS App Store and Google Play Store for apps published by "eGrowcery Pty Ltd" reveals many other tenants on the platform. This helped me find brands like Main's Market, Hitchcock's Markets, Cash Saver Stores, HMGrocerant, and Christopher's Fine Foods.

**B. PR and Case Studies**
Checking eGrowcery's own marketing and blog materials revealed other major clients like Brookshire Brothers, Willy Street Co-op, and Doc's Food Stores.

**C. API ID Enumeration (The scalable approach)**
The Rouses platform API endpoints utilize a numerical store ID (e.g., `514` for Mandeville) inside the path:
`GET /api/v1/application/stores/{storeId}/summary`

A programmatic approach to enumerate *all* stores would be to write a script that iterates `storeId` from `1` to `5000+` and makes requests to the `/summary` endpoint. Whenever a valid response is returned, the JSON body contains the exact retailer name, store location, and address.

## 3. Gaps and Limitations

My approach currently has a few limitations:
- **Cloudflare / AWS WAF Blocking**: The `noq-servers.net` API endpoints employ strong bot mitigation (AWS WAF challenges). Simple `curl` or script requests timeout or receive 403 Forbidden errors unless executed from a valid browser context that passes the telemetry checks. This prevents rapid iteration of the `storeId` enumeration via simple HTTP requests.
- **Coverage**: Finding apps by developer account misses retailers who might have deployed the platform only as a web app without a mobile app, or retailers who publish the app under their own Apple Developer account rather than eGrowcery's account.

**How to overcome these gaps:**
To execute the API enumeration at scale, I would build a distributed Puppeteer script that intercepts requests or evaluates `fetch()` from within a headless browser to inherit valid WAF cookies and telemetry tokens, iterating the `storeId` sequentially. Alternatively, using passive DNS reconnaissance (searching for all subdomains or CNAMEs pointing to `noq-servers.net`) via services like SecurityTrails or Shodan could reveal the custom web URLs for each retailer without ever needing to query the API directly.
